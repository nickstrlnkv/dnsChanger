# ⚡ DNS Changer для Windows 11 / 10

Удобная графическая утилита на **C# / WPF (.NET 10)** для быстрого переключения DNS-серверов в один клик.

## 🚀 Основные возможности

1. **Готовые пресеты DNS "из коробки"**:
   * **Cloudflare DNS** (`1.1.1.1` / `1.0.0.1` | `2606:4700:4700::1111`) — максимальная скорость и приватность.
   * **Google Public DNS** (`8.8.8.8` / `8.8.4.4` | `2001:4860:4860::8888`) — стабильность и совместимость.
   * **AdGuard DNS (Блокировка рекламы)** (`94.140.14.14` / `94.140.15.15`) — блокирует баннеры, трекеры и фишинг.
   * **AdGuard DNS (Семейный)** (`94.140.14.15` / `94.140.15.16`) — блокировка рекламы + защита от сайтов 18+.
   * **Quad9** (`9.9.9.9` / `149.112.112.112`) — защита от вредоносного ПО и вирусов.
   * **OpenDNS (Cisco Umbrella)** (`208.67.222.222` / `208.67.220.220`) — надежная фильтрация.
   * **Яндекс DNS (Базовый)** (`77.88.8.8` / `77.88.8.1`) — быстрые серверы в РФ.
   * **Control D (Anycast)** (`76.76.2.0` / `76.76.10.0`) — современный Anycast DNS.

2. **Поддержка современных протоколов**:
   * **IPv4** (основной и резервный адреса).
   * **IPv6** (основной и резервный адреса).
   * **DoH (DNS over HTTPS)** — шаблон HTTPS-запросов (например, `https://cloudflare-dns.com/dns-query`), автоматически регистрируемый в Windows 11.
   * **DoT (DNS over TLS)** — хост и порт (например, `one.one.one.one:853`).

3. **Хранение в `presets.json`**:
   * Все пресеты хранятся в человекочитаемом файле `presets.json`.
   * Вы можете добавлять, редактировать или удалять пресеты как прямо в графическом интерфейсе, так и открыв JSON в блокноте кнопкой **«📂 presets.json»**.

4. **Тест скорости (Ping)**:
   * Кнопка **«⚡ Измерить пинг»** проверяет задержку до выбранного сервера.
   * Кнопка **«⚡ Проверить пинг всех серверов»** автоматически замеряет скорость для каждого пресета, позволяя выбрать самый быстрый.

5. **Сброс и очистка**:
   * **«🔄 Сбросить на DHCP (Автоматически)»** — возвращает получение DNS от роутера или провайдера.
   * **«🧹 Очистить кэш»** — моментально сбрасывает системный кэш DNS (`ipconfig /flushdns` и `Clear-DnsClientCache`).

6. **Выбор сетевого подключения**:
   * Автоматически определяет подключенный интернет-адаптер (Wi-Fi, проводной Ethernet и др.).
   * Показывает текущий активный DNS на выбранном адаптере в реальном времени.

7. **Права Администратора**:
   * Индикатор в шапке сообщает статус запуска (🛡️ Администратор / ⚠️ Обычный запуск).
   * Если приложение запущено без прав администратора, при нажатии «Применить» Windows запросит подтверждение UAC, либо можно нажать кнопку «🛡️ Перезапуск от Администратора».

## 📦 Запуск

### Быстрый запуск готового EXE:
Запустите файл:
```
publish\DnsChanger.exe
```
*(Для изменения DNS запускайте приложение от имени администратора, либо подтвердите системный запрос UAC).*

### Запуск из исходного кода:
```bash
dotnet run
```

### Сборка нового релиза:
```bash
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o ./publish
```
